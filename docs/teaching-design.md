# 实时扩散教学页设计

教学页围绕正在运行的模型讲解四件事：扩散状态怎样变化、U-Net 每个算子怎样处理特征、CFG 与 DDIM 怎样更新图像、原生分辨率和多人共享状态分别是什么。正文由 Assets/DiffusionLab/Localization/teaching.json 提供，每页是英文、简体中文、日文三种短文，另带同页 UI 标签。正文应留在可阅读的短段落内，公式使用现场正在显示的变量名。

## 用真实计算驱动展示

图像和曲线应绑定当前选中模型的实际运行数据，而不是插值生成的说明动画。Controller 每步运行卷积/池化算子并写入 RFloat RenderTexture；可视化读取这些纹理和模型的 alpha 表。无运行状态时应标记为空闲或展示静帧，不要把历史图片伪装成当前张量。

采样步建议同时显示以下值：

| 展示项 | 当前数据来源 | 说明 |
|---|---|---|
| 时间步 t | TimeAt(localStep) | 按当前模型的索引规则取值。Tea 默认 64 步，时间表从 400 均匀递减到 1；Legacy 默认 32 步，leading spacing 为 248、240、…、0。 |
| 当前 ᾱ 与下一 ᾱ | alphaCumprod[t] 与下一时间索引的值 | 最后一步的 nextAlpha 为 1。标签应区分 ᾱ 表数组索引和模型的训练时间步。 |
| x_t、x₀、x_next | 当前/下一状态 RenderTexture、cleanPrediction | 每个完整采样步显示更新前的状态、由预测噪声推得的 x₀ 和更新后的状态。两张 ping-pong RT 会交换角色，图像标签应绑定逻辑状态而不是固定纹理名。 |
| ε_c、ε_null、ε_guided | 条件通过后的噪声 RT、空条件最终算子输出、guidedNoise | Tea 启用 CFG 时实际执行两个完整模型分支；空条件将类别嵌入置零。可并排显示两种预测及组合后的噪声。 |
| 当前算子与激活 | localLayer、层元数据、layerMemory 与 layerChannels | 标出算子名、输入/输出分辨率和通道数，直接查看当前 RFloat 激活。Tea 的 skip 位于 14×14 与 28×28 解码层；高亮对应图边及拼接后的通道。 |

当前 Tea 图的主要分辨率是 28×28 → 14×14 → 7×7 → 1×1，再从 1×1 经 7×7、14×14 回到 28×28。skip 连线分别接回同分辨率的编码器特征。每个通道是一张二维特征图，运行时将它们在 RFloat RenderTexture 中横向排布；显示器应按实际 layerChannels 分格，不能把空格误当成零通道。

## 算法与模型范围

正向加噪使用 x_t = √ᾱ_t x₀ + √(1−ᾱ_t)ε。训练目标是从带噪样本和时间/类别条件预测噪声 ε。反向采样以噪声为起点，先由模型得到有条件和空条件预测，再计算 x₀ 与下一状态。Tea 的运行实现采用 ε_guided = ε_null + 3(ε_c − ε_null)，对应论文另一种记号 (1+w)ε_c − wε_null 中的 w=2。

η=0 的更新是确定性 DDIM：

    x₀ = (x_t − √(1−ᾱ_t) ε_guided) / √ᾱ_t
    x_next = √ᾱ_next x₀ + √(1−ᾱ_next) ε_guided

Tea 的 401 项累计 alpha 表覆盖训练时间 0..400；采样时间从 400 到 1 取 64 个线性间隔点，最后令 alpha_next = 1，输出 x₀。当前 Tea 配置不裁剪 x₀。Legacy 是另一套模型：训练图像映射到 −1..1，外围以 −1 补到 32×32；它使用 256 项 alpha 表、默认 32 步 leading spacing，并裁剪 x₀。教学 UI 应随模型切换这些值，不要把一种模型的范围或时间表套用到另一种模型。

Tea 的训练图像数据域为 0..1，模型原生尺寸为 28×28；逆向过程的中间状态包含高斯噪声，数值可以暂时落在 0..1 之外。输出到 32、64 或 128 像素是最近邻采样放大，不会提升 28×28 模型的原生细节。可将 GPU 采样轨迹和训练样本网格作为说明页的静态参考，但需标明前者来自固定输入的实际 GPU readback，后者是模型生成样本；运行中面板应显示各客户端的实时纹理。

## 多人状态边界

VRChat 同步的是模型版本、模型选择、输出选择、类别、整数 seed、总步数、完成进度、运行阶段和控制权等轻量配置。每台客户端依据这些配置独立建立初始噪声并运行自己的 GPU 推理。RenderTexture、激活通道和中间采样状态都留在本机，不会作为网络图像传输。显示层应把“共享进度”和“本机完成步数”分开；慢端可能正在追赶。不同设备的浮点结果可能有小幅差别，因此相同 seed 表示相同生成条件，不承诺跨设备逐像素相同。
